# ToubarReplace

把 MacBook Touch Bar 做成订阅用量与常用 App 的触控启动台。

- 官网：https://toubarreplace.z-agent.ccwu.cc
- 原生应用：见 [`ToubarReplace/README.md`](ToubarReplace/README.md)
- 官网源码：见 [`website/README.md`](website/README.md)

macOS 14 及以上，Universal。官网可直接下载 DMG / PKG。Workspace 用量读本机 [OpenUsage](https://github.com/robinebers/openusage)。
