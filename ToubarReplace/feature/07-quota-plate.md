# 额度用量展示看板 (Quota Plate View)

## 订阅额度与用量监控看板
- 用户称呼：额度看板、用量区、OpenUsage 柱状图、剩余额度条、订阅看板、用量订阅板
- 入口：位于 Workspace 触控托盘左侧（App 区收缩后剩余的全部宽度，至少为设置「App 区上限」之外的部分）
- 关键选择器：
  - 看板容器：`QuotaPlateView`（内部基于 `NSScrollView` 实现无滚动条平滑手势横滑）
  - 空态提示文本：`"打开 OpenUsage 后显示订阅额度"`（居中半透明浅色标签）
  - 订阅卡片视图：`QuotaProviderCardView`
  - 节奏卡片（周期订阅）：
    - 重置环：`QuotaResetRingView`，环绕 Agent 图标的青色弧线表示本周期剩余时间；推荐订阅在环右上角显示琥珀圆点
    - 余量条：`QuotaPaceRowView`，`5h` 与 `周` 两行横向余量条，右侧常驻百分比（单位字符缩小）
    - 节奏刻度：每条上的白色竖线位于 `QuotaBarMetric.expectedRatio`（窗口剩余时间比例），表示匀速使用此刻应剩多少
    - 节奏颜色：`QuotaPace.classify(remaining:expected:)`，余量比时间多 15% 以上为琥珀（会浪费，优先用），少 15% 以上或余量低于 10% 为珊瑚（可能提前用完），其余为薄荷
    - 倒计时：`QuotaStackedTextView`，两行卡片在右侧分两行显示（如 `3d` / `0h`）；只有周额度的卡片在第二行显示 `重置 3d0h`
  - 按量计费卡片（如 OpenRouter）：展示对应 Agent 图标、金额数值（如 `$12.50`）与 `余额/额度` 标签，不展示虚假重置环
  - 推荐订阅高亮描边：浪费压力最大的订阅卡片自动展示琥珀色（Amber）外框描边，其贡献最高分数的额度柱呈现琥珀高亮，并自动置顶排列在最左侧
  - 额度指标直观展示：余量条与百分比同时常驻，不再区分柱状与数字模式（旧偏好 `quotaMetricDisplayStyle` 保留读取但不再影响渲染）
  - 点按打开：卡片顶层覆盖透明 `NSButton`（不使用手势识别器，`NSClickGestureRecognizer` 不允许直接触摸类型），轻触卡片打开对应工具。优先使用 `QuotaProviderLaunch.matchingCustomApp` 匹配的已固定 App（同时让对应磁贴弹跳），其次按 Bundle ID 打开已安装的 App，最后打开 `fallbackURL` 网页
  - 推荐切换提示：推荐订阅变化时，新推荐卡片播放一次 0.9s 琥珀渐隐；无常驻动画，物理栏静止时镜像不产生新帧
  - 软件回退桌面辅助 Tooltip：卡片挂载系统级 `toolTip = state.tooltip`（如 `"Cursor · 5h 92% · 周 78% · 重置 3d0h"`），物理 Touch Bar 上纯靠卡片直接渲染触控识别
- 子功能：
  - 额度卡片增量刷新：按 provider 复用既有 `QuotaProviderGroupView`，仅更新变化的额度、推荐与显示样式；重复进入 Workspace 保留卡片，资源图标在进程内缓存
  - 用量与周期常驻监控：直观展示各 Agent 订阅余量、短时消耗与重置倒计时
  - 本机 OpenUsage 数据联动：优先异步请求 `http://127.0.0.1:6736/v1/limits`，失败则回退执行本地 CLI `OpenUsage.app/Contents/Helpers/openusage`
  - 智能浪费压力排序：计算单窗口浪费压力 `pressure = remainingRatio / cycleRemainingRatio`（下限 1% 防除零），胜出者自动排到看板第一列并高亮提示优先消耗
  - 左右手势平滑横向滚动：当启用的订阅数量较多无法在有限宽度内排下时，保持最小列宽（三柱卡片 ≥ 144pt，双柱卡片 ≥ 104pt），右侧露出下一列裁切边缘，支持手指直接横滑翻阅
  - 毛玻璃触控横滑同步：手指在物理 Touch Bar 的用量区横滑，`QuotaScrollState` 同步视口、内容宽度和横滑位置，桌面原生卡片即时跟随；溢出范围以物理栏为准，桌面尺寸变化映射同一横滑位置，沿用原有毛玻璃外观与控件
  - 自动定时刷新：进入 Workspace 时立即触发刷新，运行期间每 5 分钟轮询更新一次快照
- 前置条件：本机安装并运行 OpenUsage；本地 API 或命令行可正常读取用量数据
- 常见故障现象：
  - 始终显示「打开 OpenUsage 后显示订阅额度」：未运行 OpenUsage，或本地服务端口 `6736` 未监听且 helper 路径不存在
  - 推荐卡片不停左右跳动：旧版本曾错误全表排序，现行策略仅把赢家置顶、其余保持稳定顺序，赢家变更时自动回滚到最左侧
